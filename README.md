## Versioning

All projects in this repository follow `x.y.z` (major.minor.patch):

- **patch (`z`)** — every patch/commit bumps `z`.
- **minor (`y`)** — every feature or addition; a minor bump requires explicit
  confirmation before it is applied.
- **major (`x`)** — stays static at 0 until we have a first release-ready
  version.

See `xcp-bundle-analyzer/RELEASE_NOTES.md` for the per-version history of the
analyzer.

## v2v vm disk progress

### How to Use

Save the script as vm_disk_progress.sh.
Make it executable:

`chmod +x vm_disk_progress.sh`

Run it with the VM name:

`sudo ./vm_disk_progress.sh myVm`

## xcp-bundle-analyzer

Rust CLI to analyze status-report bundles generated by xen-bugtool (XCP-ng / XenServer).
Parses the bundle (tar/tar.gz/tar.bz2/zip), makes xapi-db.xml usable (hosts, SRs, VDIs,
VMs, VIFs, PIFs, PBDs, dom0 config) and outputs text, JSON or a self-contained HTML
dashboard. Supports a consolidated pool view when several bundles are given.
See `xcp-bundle-analyzer/README.md`.

## xoa-support

GPL-2.0-only toolkit to collect, scrub, optionally anonymise and inspect support
bundles from a Xen Orchestra Appliance (XOA), for airgapped troubleshooting.
Includes a sos report plugin (`sos report -o xoa`), a no-dependency standalone
collector, a strict scrubber/anonymiser (`xoa_scrub.py`) and a bundle inspector
(text/JSON). See `xoa-support/README.md` and `xoa-support/docs/`.
